# Asset and material pipeline

Offline recipes are authoritative. Analytic profile geometry for dimension-critical regular parts; optional Blender headless workers for bevels, unique UV/baking and higher quality previews. Original research assets are probes, not production catalog. First correct fit bounds, anchors, LOD silhouette, hard edges, UV and normal orientation; then windows/doors/balconies/HVAC/roof elements. Never stretch fixed profiles indiscriminately; rebuild or quantize within stated fitting tolerance. Asset cache keyed by canonical recipe, generator revision, tool version, material schema and processing options. Modules mounted from ArchitecturePlan with stable IDs. No manual DCC operations required.
MaterialRecipe -> source maps -> QA -> target compression and array/atlas packaging. Canonical BaseColor sRGB, Normal linear tangent +Y (target verified), ORM linear R AO/G roughness/B metalness, optional height in physical units and emissive. UV0 metric/trim, UV1 unique bake or declared metadata, never both without contract. AO not baked sun, painted metal dielectric. Preserve directional roof patterns, use macro variations and semantic weather masks. Shared resources globally, avoid one material per building. Test normal convention and target channel packing in SDK. Near geometry vs distant mask from same plan; stable window occupancy across LOD, linear emission mip average. 
Lab stages: actual model roundtrip, orthographic CPU depth-buffer previews (geometry, top/side/3-quarter, fixed framing), material contact sheets, LOD side-by-side, optional Blender CPU Cycles PBR render of selected models/blocks. GLB render does not prove UNIGINE shader parity. Generated binary models/PNGs as CI artifacts, not every commit. Promote small curated golden fixtures after review. Source imagery and third-party assets only if redistribution allowed; keep provenance.
