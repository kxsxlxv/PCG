# Technical specification — staged delivery

MVP-A (SDK-free) is the first deliverable: reproducible CLI, small original fixtures and authorized optional local AOI, robust flat/gable/convex-hip roof, constrained triangulation incl holes, deterministic basic architecture profiles and facade placements, material IDs, actual render meshes and GLB, explicit fallback/reject report, CPU visual QA. Start single simple building, then 18 archetype fixtures, then small neighborhood. Real GIS adapter and fusion increment separately; complex concave roofs, full overlapping parts union, sloped foundations implemented/tested incrementally, not disguised as solved by probes. No mandatory Blender, no AI, no SDK. Baseline preview is diagnostic, not photorealistic target.
MVP-B independent compiler: authorized Adler pilot bbox 39.91,43.42,39.94,43.44; audited source snapshots and DTM; semantic topology, more archetypes, modular assets, PBR library, authored LOD, tile manifests and synthetic scheduling. Review reference renders at street and aerial scales. Native integration deferred until small core is accepted. MVP-C native adapter: G0–G8 on workstation, native packer and shared materials, mesh batches/cluster tests, then G9–G12 runtime and performance. Never assign entire project in one prompt. 
CLI contract proposal: pcg validate-input, pcg compile --config --input --out, pcg inspect, pcg lab render --manifest --out, pcg lab verify. Inputs explicit, no implicit network; nonzero on invariant failure, documented fallback decisions not silent drops; structured logs and manifest. Outputs neutral GLB + semantic plans/metrics + previews, later native packer consumes canonical data. 
Out of scope until later approval: global Earth terrain, vegetation/roads, full interior simulation, neural training/inference in default CI, procedural destruction, custom renderer, production 100k buildings before measured pilot, paid GPU or self-hosted runner installation. See [acceptance](TESTING.md).
