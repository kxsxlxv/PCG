## L2.1 acceptance / L2 geometry fixtures
2026-11-25: PR #4 head f3661de050ad4b8363cdd7d5920849def4f30378, run 45554370633, 10 unit tests and 7 probes PASS; artifact 14995225816 exact head. Nonvisual contract change. Merged as 4bcda8ce7ccdf7c1520bcab36aff52e66336c213. Main verified before starting new branch.
Following user request to batch related increments, this PR combines remaining L2 massing, repair and roof fallback, 13 synthetic fixtures, exported GLB verification and fixed-camera depth-buffer previews. Uses already-pinned Shapely 2.1.2 constrained triangulation and convex lower-envelope edge planes. Flat caps are triangle surfaces with explicit seam edges, not yet merged semantic polygons. Repair is deliberately limited to exact consecutive duplicate removal, zero area change; self-intersections, touching holes and ambiguous topology rejected. Gable supports rectangles (including rotated); equal-pitch hip supports strictly convex hole-free footprints with valid manifold cells; unsupported pitched cases fall back to flat with reason. General skeleton, arbitrary concave pitched roofs, topology-changing repair, multipart union and terrain are not implemented. CI and actual image acceptance pending; do not merge until verified. No SDK, GPU or new dependency.
