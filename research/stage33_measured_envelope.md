# Stage 33 measured envelope experiment
Runs on exact donor files. Extracts area-weighted orthogonal facade orientation,
32 cross sections, normalized rectilinear tiers, and provisional low-roughness
atlas-region centers via actual UV-triangle barycentric inversion. Estimates
repeat periods and module dimensions, exports independently generated tier meshes
and compares two neutral orthographic silhouettes per sampled source. Source
atlas sampling is explicitly provisional where material bindings are absent.
Not a finished architecture generator: pitched/nonrectangular forms, semantic
classification, exact physical dimensions, full PBR, and integration into the
existing Stage32 facade grammar still require validation. Source files are
published only by explicit owner authorization as separate short-lived artifact.

Contour pass: polygonize snapped section linework, preserve disjoint components and concavity, retain explicit fallback, compare against rectangular baseline at 1280x960. UV periods smaller than candidate module size are rejected. No finished facade or native GIS integration claim.

High-poly only: recover incomplete cross sections from adjacent vertical wall samples and cumulative observed horizontal cap projection. This is a conservative heuristic, not authoritative occupancy; visually reject false storey gaps or filled courtyards.
