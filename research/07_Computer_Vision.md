# Research 07 — Image enrichment: classical CV and pretrained models

Date: 2026-11-24 | PCG | UNIGINE 2.22 | RTX 5070 Ti, single workstation.
Retrospective report from completed stage 07; no new model training or inference in this report. User constraints: no training, fine-tuning or manual model tuning; use already trained task-specific weights, selective inference only, sensible time budget. No runtime AI. Do not detect existing GIS footprints again.

## Decision
Base compiler works without PyTorch or imagery. Data Fusion first: OSM, Overture, GBA, Microsoft, ЖКХ etc. ImageEnrichment produces attribute observations only for missing or disputed attributes; never destroys original geometry or overrides known reliable tags. Classical CV first where suitable: apparent roof color, edge/ridge hypothesis scoring, facade statistics. Pretrained optional narrow models only where gain justifies cost. No universal SAM contour detection, monocular-depth city-wide height estimation, generative 3D per building, large VLM per-building, or runtime inference. GBA/other height estimates already computed; preserve uncertainty and measurement semantics, not treat estimates as ground truth.
Modes: Base (no imagery/ML), CV (CPU image observations), Enhanced (optional pretrained selective inference). Missing imagery/model, OOM, unsupported classes, uncertain results or budget exhaustion -> grammar fallback, never drop building.

## CPU roof appearance
Known footprint → raster CRS and mask → erosion with alignment uncertainty/GSD → reject invalid pixels (shadow, vegetation, nodata, occlusions) → median CIELAB and robust dispersion → apparent color observation → material palette selection. Source RGB is not PBR albedo; illumination, atmosphere, seasonal variation and sensor color differences matter. Off-nadir approximate displacement H*tan(theta), e.g. 12m at 20deg ~4.4m. Use true ortho/roofprint where available, preserve geometric source and uncertainty; reject when safe sample too small. For mixed roof use per-part sample where possible, not forced uniform. GSD 0.3–0.5m useful starting hypothesis for small roofs, not guaranteed. Sentinel-2 10m not suitable individual houses.
[OpenCV LineSegmentDetector](https://docs.opencv.org/4.13.0/db/d73/classcv_1_1LineSegmentDetector.html), Canny/Sobel/Hough/RANSAC: compare lines against candidate gable/hip ridge and valley projections from known contour, not assume each detected line is ridge; shadow/material seams/occlusion confound. Keep OSM roof tags if reliable. Not implemented in stage 07.

## Executed experiment
[roof_color_probe.py](07_cv/roof_color_probe.py), [roof_color_results.json](07_cv/roof_color_results.json). Python NumPy 2.3.5, OpenCV 4.13.0, single CPU thread. 600 synthetic 96x96 chips with known footprints, contaminated perimeter, marked invalid pixels and random noise; 600 accepted; mean Delta E76 12.147 naive mean vs 0.116 robust; robust p95 0.245. 0.303s sum of observation calls (0.505ms/chip), excludes raster I/O, geospatial prep and fixture generation. 600 high uncertainty cases abstained, heterogeneous red/white sample abstained. Supplied invalid mask is synthetic ground truth, NOT automatic shadow/vegetation detection. No real imagery, GPU, learned models or albedo recovery. ## Imagery and validation
Prefer own licensed orthophoto used for terrain, OpenAerialMap where actual local coverage exists, authorized commercial imagery; Mapillary/KartaView for authorized street reference access and attribution. No indiscriminate scraping. Need actual Adler imagery access, source dates/GSD/ortho method/camera metadata/license, not verified in stage 07. Crop once per tile/read raster windows with shared buffers. Street photos require pose/view selection and rectification. Rather than analyze every facade, use a stratified reference sample (proposed 560 across residential, guest houses, panel/brick, modern, hotels, industrial, sanatoria) to estimate grammar priors, not train ML. Validate with independent reference labels, e.g. 200–400 stratified buildings; per-class precision/recall, confusion, abstention/coverage, uncertainty, time. Compare model vs grammar baseline; retain only if meaningful gain, no training. Probabilities not calibrated confidence; preserve raw class scores and metadata, reject domain mismatch. Proposed acceptance thresholds to be decided against pilot.
Observations: building/part ID, attribute, value, method, model revision/hash or algorithm revision, source raster ID/epoch/GSD/CRS/pose, crop hash and alignment, confidence/quality flags, candidate/accepted/abstain, timestamp. Never overwrite high-confidence surveyed attributes. Preserve conflict ledger.
