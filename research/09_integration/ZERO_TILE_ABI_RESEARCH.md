# Research neutral tile ABI v1 (SDK-free candidate)

Input: `lab/compile_zero_tiles.py --input INPUT.json --out OUTPUT`. See self-test artifact input_128.json. Requires explicit projected metric ENH frame and vertical datum, origin double, tile size, stable IDs, source reference, canonical local footprint/holes, anchor relative to frame origin, eave/floors/profile, roof/rise and party edge indices in canonical ring order. Synthetic frame is not georeferenced data. No automatic GIS fusion/DTM. Entire building belongs to centroid tile, bounds may extend outside nominal tile. Roof fallbacks reported, invalid input rejected rather than silently dropped.

One GLB node/mesh per tile with 3 role primitives, Y-up interchange. Native Z-up position=(x,-z,y); world anchor from manifest. Raw TEXCOORD_1 unwrapped u,z meters; COLOR_0 normalized byte index R+256*G, same across triangle. TEXCOORD_0 repeat units, glTF V convention. Generic viewer uses ID colors; requires custom material. Use native adapter to verify no UV1/byte reinterpretation, correct tangent convention and local transform.

facade_params.bin: 16-byte little-endian header magic PCGF, version u32=1, count u32, stride u32=112. Each 112-byte record = 12 uint32 then 16 float32, fields in index.json. Role flags: low2 role wall0/roof1/base2, bit2 party, bit3 courtyard, bit4 door. Cell offset and floor/bay count index shared numeric byte table, no image per building. Surface/building seeds two uint32 each, stable from SHA-256 first 8 bytes; record index ephemeral. Material index matches sorted shared PBR library manifest. 112-byte payload per semantic record, not measured VRAM. Cell code low2 role 0 blank/1 window/2 balcony access; high bits static emission variant 0/1/2. Door exception rectangle in record. Reserved words zero. Data table CPU byte contract, not proof of native buffer/texture access. Independent C++ decoder uses explicit endian parsing and bounds checks, no SDK headers.

Shared material source library: all current recipe layers same selected resolution, basecolor sRGB, normal linear +Y, ORM linear. Native compression, array allocation, mip generation and sampler availability not demonstrated. No per-building image texture. Canonical dynamic occupancy/lighting/filter integration still pending. Native G0–G12 required, plus actual shader and visual quality, foundation and balcony volume decisions. This is a research lane, no production contracts changed.
