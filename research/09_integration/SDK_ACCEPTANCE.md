# SDK 2.22 — Local acceptance gates

Status: **NOT EXECUTED**. These are mandatory tests for the installed licensed SDK; coordinate probe is independent. Do not treat successful documentation review as successful compilation. Use the actual SDK-generated project and local headers as authority. Keep the native adapter small and stop at the first failing gate, document the fallback or correct the design before scaling.

## Prerequisites
Record exact SDK build, edition, SDK Browser/project template, host OS, compiler/toolset, architecture, Debug/Release, engine precision, renderer API, plugins, driver, CPU/RAM/storage, resolution. Build a standalone C++ double-precision project using SDK Browser. If host simulator precision is different, verify integration ABI or use agreed host coordinate policy. Do not check SDK files, binaries, license credentials or external imagery into public GitHub. Use an isolated test data directory. Test each change in a small world and store result logs/screenshots and versioned settings.

| Gate | Fixture and procedure | Pass condition | Fallback if not supported |
|---|---|---|---|
| G0 SDK and app | Generate official C++ template, run empty world, record build; inspect local header signatures from research 09. | Debug and Release builds run; world lifecycle valid; no ABI mismatch. | Pin installed SDK/compiler; do not port based only on older docs. |
| G1 mesh I/O | sdk_smoke_candidate.cpp panel, add asymmetric second panel with different UV/hard edge, save/load native MESH; use real paths/material. | Correct counts, bounds, surface role, meter scale, winding and UV/normal appearance; no missing/degenerate geometry after reload. | Official importer for offline conversion, inspect native Mesh attribute/index conventions. |
| G2 import | Import stage 03/04/05 assets via SDK/editor, compare known asymmetric marker/axes, dimensions and PBR mapping. | No double Y-up→Z-up conversion, no missing textures or material references; deterministic semantic surface mapping. | Use direct mesh adapter or official FBX path; separate material assignment. |
| G3 shared cluster | Same module 16, then 1k/10k instances, local mat4 with root world transform; compare ordinary static nodes. | Correct placement, transform, culling, material references and LOD; log CPU/GPU/draws per pass. | Spatial batches/limited palette groups; no assumption about draw count. |
| G4 custom parameters | Declare pcg_variant uint and pcg_wear float once; graph Current Surface Parameters drives two strongly distinct colors. Set instance 0/1 independently, one shared material. Repeat at different frame/view/LOD. | Colors correct in object's own geometry pass (not post-effect); no material copies, no cross-instance contamination, correct shadows/depth; measured overhead acceptable. | Bounded shared palette groups; packed mesh attributes for unique batches. |
| G5 merged geometry | Same surface containing two disjoint buildings with different attribute IDs; verify UV1/color import and constant triangle attributes; no lightmap conflict. | Correct discrete layer and tint without interpolation across roles. | Split surface into bounded material groups. |
| G6 arrays/PBR | 2-layer red/green array and asymmetric normal/ORM maps, verify mip chain, sRGB/linear and BC format/residency; read graph layer index. | Correct layer, orientation and shading; no cross-layer leak, memory recorded. | Smaller banks, atlas with mip-safe gutters, shared conventional materials. |
| G7 flat terrain | Synthetic 2x2 or small grid with known extent/height gradient; create .lmap through documented LandscapeMapFileCreator workflow or import manually; no Sandworm; sample with LandscapeFetch. | Four control anchors + interior samples agree within declared grid quantization/interpolation tolerance; correct north/east, pixel centers, units, vertical offset, no floating foundation. | Explicit WorldFrame adapter and corrected raster preprocessing; no mixed datum/curvature. |
| G8 precision | Known Adler WGS84/UTM anchors and 512m local tile vertices. Compare engine placement/roundtrip against PROJ, check seam at neighboring tile, camera movement and far origin. | Numerical horizontal/vertical transform agreement within proposed 1 cm for synthetic control points; real data tolerance separately source-limited. No visible jitter. | Double SDK, smaller local origins or host-specific floating-origin policy. |
| G9 async readiness | Precompiled mesh and material, request while inactive, inspect documented current/async VRAM methods; test cold/warm cache, shader cold/hot, cancel, missing file, world reload. | No main-thread blocking loop or stale callback; record read/CPU/GPU/first-correct-frame latencies; determine reliable readiness contract. | Pre-warm resources/shaders, conservative fallback retention and bounded activation. Never declare file read ready. |
| G10 HLOD | Two levels with disjoint child ownership, delay one child, cancel during load, teleport and return, repeat 100 cycles. | No missing coarse coverage inside resident test area; no duplicate parent-child geometry outside intended transition; no unbounded memory growth; no late activation. | Retain parent and restrict refinement; instrument state transitions. |
| G11 collision | Solid near proxy, visible separate mesh, ray tests and supported physics contact; tile boundary, passage, roof and HLOD swap. | No duplicate collision or missing proxy in active collision radius; ray hit mapped to stable building ID; no false claim that render surface flag implies rigid body. | Simplified explicit proxy and CPU spatial query. |
| G12 pilot perf | Actual available Adler AOI; baseline terrain without buildings vs individual nodes vs spatial batches vs clusters/hybrid. Use stage 08 scripted route/settings. | Raw frame-time and memory logs, p50/p95/p99, pass counts, queue metrics, cold/warm, day/night and repeated flight. Decide budgets using actual workstation. | Lower complexity or choose better spatial granularity; no fabricated FPS. |

## Recording results
For each gate record state (NOT_RUN/PASS/FAIL/BLOCKED), SDK/compiler/precision, exact command/project commit, settings, fixtures, raw logs, metrics, images, error and decision. A gate can pass functionally while failing performance. Do not mark PASS without actual execution. Numerical coordinate experiment in research 09 does not pass G7/G8 in the engine. The proposed thresholds and fixtures are initial engineering decisions, not guaranteed capabilities. Start G0-G6 before implementation of the full compiler/runtime. Keep production work blocked on essential native integration contracts but allow independent geometry/grammar development.
