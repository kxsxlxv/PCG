# Stage 29 — private PBR replay and reference assets

Research-only. Stage 28 remains the immutable geometry/ABI baseline. The new
offline replay reads the original bundle, checks all SHA256 hashes and reconstructs
the existing renderer. It supports the 14 explicitly supplied source archives
without committing any binary data. 18 of 20 existing palette slots can be
overlaid, 3 as hybrid painted timber while retaining board seams; 2 standing
seam slots remain procedural. Source scale is estimated, not measured. Separate
maps and ARM/EXR inputs use explicit linear data channels, OpenGL normals,
linear-light albedo resampling, square tiling of rectangular maps, and metadata
repeat updates limited to compatible opaque records. Existing synthetic brick
cell tint is disabled for imported photographic bricks. Paving, peeling metal
and structured tiled facade are normalized but held out pending semantic mapping.

CI uses only original synthetic fixtures. A private replay must be run separately,
with the exact CI66 artifact extracted under artifacts/ and the user-provided
archives outside the checkout:

    PYTHONPATH=src python lab/zero_reference_assets.py --private-materials /path/to/archives --out /path/to/private-output

The output includes per-source checksums, normalized maps, overlay manifest, actual
baseline/candidate render pairs, and preserved stage-28 scene metadata. The
private output must not be uploaded to a public CI artifact or repository.
Source archive for the replay contains only already-tracked lab/src/approved assets.

Reference mesh intake: buildings_2012.zip includes 54 named mesh nodes and 14,924 input triangles (14,916 non-degenerate)
 across mesh definitions; the separate glTF has 50 mesh definitions and
670,747 non-degenerate triangles after strip triangulation across definitions, with inline geometry but separate PBR maps.
Three equipment families have three LODs each. They require EXT_meshopt_compression,
KHR_mesh_quantization and KHR_texture_basisu; existing uncompressed PCG importer
does not decode these. Do not copy donor models or infer licenses. AC LOD0 alone
exceeds the current whole-building 1,800-triangle cap. All nine meshes were decoded locally using the upstream MIT-licensed meshoptimizer
v0.20 JS reference algorithm; index ranges, accessor extrema and non-degenerate
triangle counts were checked and actual geometry contact sheets inspected.
BasisU texture decoding and budget-preserving procedural variants remain pending.
Local real-input audit found corrugated iron ARM AO MAE 0.06007; separate
AO and roughness maps take precedence and the mismatch is logged. No change to source GIS, geometry or LOD in
the PBR replay. No native UNIGINE SDK claim.

## Full reference replay with original equipment

The earlier CI 68 passed every workflow step. Its source and visual ZIPs were
downloaded and matched their GitHub SHA-256 digests. All 144 stage-28 manifest
entries were checked. Real-input local EGL replay with the supplied 14
archives passed all seven fixed camera pairs, exact silhouette masks, 1728
texture samples and 18 palette replacements. Photographic brick/concrete detail
is stronger; dark aged tile and light brick change the palette, and close glass
and shadow resolution still look stylized. Three normalized source families
(paving, painted metal, structured concrete tile facade) are not assigned.

The final original equipment recipes fit the previous oriented bounding boxes:
two AC bracket heights, dual-fan roof air handler, and twin open stacks with
8-sided Near / 6-sided Lite tubes. Use stable placement IDs and a whole-building
1800-triangle gate. Preserve every old anchor; 50 upgrades accepted and 11 retain
the original shape in both LODs. Lite now retains all 61 equipment anchors
instead of omitting them. The 4 variants are represented by 21, 17, 6, 6 upgraded
placements. Per module Near/Lite: AC 60/36, handler 68/56 including existing
flashing, twin stacks 116/92 including existing flashing. Total 33,368 Near and
20,680 Lite triangles, max 1,798. Actual ownership counts, old non-equipment
triangle streams, byte-identical GLBs under reversed iteration, 8 exact source
file hashes, and all cutout face IDs checked. UV0 is metric; research shader
uses disjoint equipment-local UV1 tags for brackets, round fans and grilles.
Fan blades/relief are analytic shading, not new mesh. Native adapter still
requires implementation. No Far LOD or additional donor building grammar
claimed. Local real and synthetic replay passed before publishing, both with
15 actual rendered views and neighborhood Near/Lite mask IoU 0.9977783338.
Closeups have a full-frame building/roof background, so their mask IoU is not
an isolated equipment silhouette metric. Visual iteration corrected original
box-vs-twin-stacks LOD mismatch and overly elliptical fans.

Reproduce with a private overlay generated by the preceding command:

    PYTHONPATH=src python lab/zero_reference_equipment.py --overlay /path/to/private-output --out /path/to/private-equipment-output

Public CI runs the same code against the existing original synthetic overlay.
Private real assets and derived private images are never committed. Local
software EGL is not native GPU performance or UNIGINE validation.
