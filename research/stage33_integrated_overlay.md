# Stage 33 opt-in overlay
Replays exact accepted Stage32 Near/Lite GLBs and PCGF payload from verified
artifact. Appends cropped donor modules to shared material arrays. A fourth
opening texel (research GPU-side sidecar, not a native ABI change) selects
compatible ordinary unpaired windows by stable facade stack and aspect.
Opaque donor wall patches are used only outside openings and with roughness
and clearance guards. Existing window/door, balcony, roof, night state and
cutout semantics remain authoritative. Day-only blend; no native GPU claim.
No additional triangles. Sixteen matched synthetic GIS buildings and four
day/night closeups; identical day masks and byte-identical night closeups
are required. The baseline and candidate use the same material bank and
renderer, with an explicit uniform switch. This does not solve semantic
classification, authoritative GIS building parts or native UNIGINE integration.
